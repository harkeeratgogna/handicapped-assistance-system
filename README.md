# Handicapped Assistance System

An Arduino-based assistance prototype designed to help people with disabilities communicate predefined needs through simple user inputs while providing basic health monitoring.

## Project Overview

The system was developed as a working hardware prototype at Chitkara University.

It uses push-button inputs connected to an Arduino to allow the user to select predefined requirements. The selected requirement is communicated to the caregiver through an LCD display and audible/visual indicators.

The prototype also integrates an ECG sensor and DHT11 temperature sensor for basic real-time health monitoring.

## Features

- Push-button based user input
- Arduino-based control system
- LCD display for user/message feedback
- ECG sensor integration
- DHT11 temperature sensing
- Audible alerts using a buzzer
- LED-based status indication
- Battery-powered prototype
- Physical hardware implementation

## Working Principle

1. The system receives input from the user through push buttons.
2. The Arduino processes the selected input.
3. The corresponding requirement is displayed on the LCD.
4. Audible and visual indicators provide additional feedback.
5. ECG and temperature sensors provide basic health-related measurements.
6. The system operates as a physical prototype using a battery-powered circuit.
